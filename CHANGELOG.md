# Changelog

## [0.1.0] — 2026-10-15

First open-source preview release.

- Local webcam scanning with immediate capture and manual confirmation.
- CSV-backed loose inventory and bag locations.
- Configurable maximum pieces per bag.
- LEGO set part tracking via Rebrickable, including minifigure parts.
- Priority allocation to an active set and separate numbered set bags.
- Image-assisted bag-by-bag picking with staged, confirmed transfers.
- Possible Matches for recorded colour variations; manual verification required.
- Green highlighting for fully collected part requirements.
- Initial test suite, release documentation and CI configuration.

This is a **preview**, not a security-audited or field-validated production release.
